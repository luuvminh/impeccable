## Impeccable

Repo này có Impeccable v4.1.1 cài cục bộ (`.claude/skills/impeccable/`) — mọi phiên Claude Code
mở trên repo tự nhận, không cần setup.

Khi Max hỏi bất cứ điều gì về Impeccable — cách cài, `/impeccable init`, danh sách 23 lệnh, detector,
hook, live mode, `.gitignore`, anti-pattern — **đọc `docs/impeccable-getting-started.md` trước khi
trả lời**, đừng trả lời từ trí nhớ. Đó là bản lưu của
<https://impeccable.style/tutorials/getting-started/> (miền này bị chặn egress trong Claude Code
trên web, nên tài liệu được dựng lại từ repo chính chủ và bản v4.1.1 đang cài ở đây).

Bản tra cứu ngoài repo: Notion 📚 Library → "Getting started | Impeccable"
(<https://app.notion.com/p/3bea6a4617f48190b74cf26a07611811>), dùng cho các phiên Claude không mở repo này.
